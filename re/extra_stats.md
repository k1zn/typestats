# Form3 «Дополнительная статистика» (0x43ff3c)

Порт — `src/core/ExtraStats` (готов; `tests/tst_extra.cpp` — синтетика, `tst_orig` — сверка с оригиналом на 824.tsf:
вектор строк из памяти побитно + текст списка, 58 снимков: типы 0–5 × средние, все режимы сортировки, нижний список,
11 шаблонов, фильтры, выделения). Все находки ниже проверены по декомпиляции и `disasm.py` (литералы WideString,
пороги x87).

## Когда считается
- `FUN_0043f7f0` (FormShow, изменение фильтра `TntEdit1Change`): собирает множества символов фильтра, затем 0x43ff3c.
- Recalculate в конце: если Form3 видима (`+0x57`) → 0x43ff3c; если видима Form4 → 0x451b88.
- Смена выделения в главном окне, RadioGroup1Click, CheckBox2Click, TntEdit5Change (текст шаблона) → пересчёт.
- CheckBox1 «Заблокировать» (`+0x2f8`) отмечен → не считать, только флаг `DAT_0059b769 = 1` (пересчёт при снятии).
- Если после расчёта видима Form4 (`Form3+0x360`) → `TForm4::FormShow`.

## Диапазон и данные
- Диапазон элементов `[b, e)` — `FUN_004252fc`, тот же, что у основной статистики (`Stats::range`).
- `names[i]` (`DAT_005b1410+0x40`), `erased(i)` (bitset `+0x58`), `pause[i]` (`DAT_005b1408`, < 0 — начало фрагмента),
  `finger[i]` (`DAT_005b1404`, см. finger_zones.md).
- Enter в модели — элемент с именем `"\r"`. Преобразование `FUN_0043f6e8`: `"\r"` → `"[Enter]"`, иначе имя как есть
  (для n-грамм и слов; шаблон добавляет имя без преобразования).
- Тип = RadioGroup1.ItemIndex: 0/1/2 — 2/3/4-символьные сочетания, 3 — слова, 4 — слова с ошибками, 5 — предложения,
  6 — шаблон. CheckBox2 «Средние значения» (`+0x2fc`).

## Скорость
Сумма пауз — float (`fadd dword; fstp dword` на каждом шаге), паузы элементов k ≥ 1 (без первого).
`speed = float((long double)(L·60000 − 60000) / sum)`, иначе 0:
- n-граммы: при `sum > 10.0f` (0x4430cc), L = n;
- слова/предложения/шаблоны: при `sum > 0.01` (double 0x4430c4); L — длина строки (слова) или шаблона.

## n-граммы (тип 0..2, n = тип + 2)
```
for p in [b, e − 1 − тип):
  для k in 0..n−1, i = p+k: если erased(i) или (k≠0 и pause[i] < 0) → пропуск p
                            text += transform(names[i]);  k≠0: sum += pause[i]
  если filter(text): добавить (speed, text, p)
```

## Слова / слова с ошибками / предложения (тип 3/4/5)
Перебор p от b до e **включительно** (p == e — конец). `cur` — текущее слово, `start`, `sum`, `hadErr`, `sentEnd`.
```
end = p >= e; name = end ? "" : names[p]; sep = end
если !end:
  sep = (name == " " или name == "\r") и !erased(p)
  brk = sep и (тип ≠ 5 или sentEnd)
  если name == "\r": brk = true
если !brk и pause[p] < 0: brk = true              // начало фрагмента
иначе если !brk и cur непусто: sum += pause[p]
если brk:
  тип 4: hadErr = !hadErr;  тип 5: hadErr = false
  если len(cur) > 1 и !hadErr: speed по len(cur); если filter(cur) → добавить (speed, cur, start)
  hadErr = false; cur = ""
если cur пусто и !sep: start = p; sum = 0
если cur непусто или !sep:
  если !erased(p): cur += transform(name); sentEnd = name ∈ {".", "!", "?"}
  иначе hadErr = true
```
(При «Только текст» = 0 в слова попадают и длинные имена клавиш, например `[LShift]` — как в оригинале.)

## Шаблон (тип 6)
Строка из TntComboBox1. Разбор: обычный символ → код 6 (литерал); после `/`:
`б`→0 строчная русская (а-я, ё), `Б`→1 заглавная (А-Я, Ё), `*`→2 любой, `0`→3 цифра,
`,`→4 знак (символ ∈ ``"`~!@#$%^&*()_+|/=-?:;№\"[]{}'<>/\\.,"``, 0x59baa4), `е`/`e`→5 ошибка (стёрт),
`c`/`с`→10 строчная латинская, `C`/`С`→11 заглавная латинская, `1`..`9`→7 палец (`char−'1' == finger`),
`(`/`)`→9 рука (`finger ≤ 7` и `(finger < 4) == (char == '(')`), `/`→8 символ `/`, прочее → литерал 6.
Для каждого кода запоминается сам символ шаблона. Длина L = число кодов.
```
for p in [b, e − L + 1):
  для k, i = p+k: name == "\r" или (k≠0 и pause[i] < 0) → нет
                  ch = len(name)==1 ? name[0] : 0
                  erased(i) и код ≠ 5 → нет; иначе проверка кода
                  text += name; k≠0: sum += pause[i]
  если всё совпало и filter(text): добавить (speed, text, p)
```

## Фильтр по символам (0x43fcac)
Три флажка с полями: «Только эти» (CheckBox3/TntEdit1), «Один из» (CheckBox4/TntEdit2), «Исключить» (CheckBox5/TntEdit3).
```
pass = !«Один из»
для каждого символа c строки:
  «Только эти» и c ∉ A → false
  !pass и c ∈ B → pass = true
  «Исключить» и c ∈ C → false
```

## Сортировка и вывод
Строка списка — `{float speed; int value; WideString text}` (вектор `DAT_005b1544`). value — позиция (номер элемента
начала) или, в режиме средних, количество. Сортировка `DAT_0059b764`, обратный порядок вывода `DAT_0059b768`.
- ColumnClick: столбец 0 → режим 0 (повторный клик — обратный порядок), столбец 1 → режим 1 (аналогично);
  при переходе на другой столбец направление **сохраняется** (проверено стендом: режим 1 ▼ → клик по «Скорость» →
  режим 0 ▼). Столбец 2 (только в режиме средних) → режим 2, повторно → 3; обратный порядок сбрасывается.
  Снятие «Средних» при режиме > 1 → режим 0.
- Без средних: режим 0 — по скорости по возрастанию, режим 1 — по тексту (ординально UTF-16, `_WStrCmp` 0x4c98d0);
  обе сортировки устойчивы (multimap, равные — в порядке добавления, т.е. по позиции).
- Средние: все вхождения в multimap по тексту; группы равных текстов: `count`, `sum` (float), `avg = float(sum / count)`
  (деление в long double). Режим 0 — устойчиво по avg; 1 — по тексту; 2 — (count ↑, text ↑); 3 — (count ↓, text ↑).
- Вывод строки i (при обратном порядке — `n−1−i`): столбец 0 `FloatToStrF(speed, ffFixed, 8, 2)` (десятичный
  разделитель локали; округление — половина от нуля;
  ограничение в 8 значащих цифр сказывается только от 1 000 000 и в порту не воспроизводится), 1 — текст, 2 (только в режиме средних) — `IntToStr(value)`.
- Заголовки столбцов: «Скорость», «Текст», «Кол-во» (`DAT_0058e268/26c/264`); у столбца текущей сортировки
  префикс `▲` (U+25B2), если порядок прямой и режим ≠ 3, иначе `▼` (U+25BC).
- Строка состояния: «Всего: N» (`DAT_0058e260` + " " + число строк).
- Выбор строки: без средних — клавограмма прокручивается к элементу value (`FUN_004050cc`: время записи клавограммы
  минус 100 мс). Со средними — нижний ListView2 показывает все вхождения этого текста, устойчиво по скорости
  (multimap float), столбцы «Скорость», «Текст»; выбор вхождения прокручивает клавограмму.

## Кнопки

- Сохранить (txt, `TStringList`, ANSI): заголовок `Текст\tСкорость[\tКол-во]`, строки `текст\tскорость[\tкол-во]`
  (в порядке вывода).
- Excel: те же столбцы (`ExcelGraph`).
- Шаблоны: список TntComboBox1 = `<exe>\ExStats.ini` — **не INI**, а список строк TntStrings (UTF-16 LE с BOM;
  при чтении — BOM/ANSI). SpeedButton8: добавить текущий текст, если его нет, и сохранить; правой кнопкой — удалить.

## Для стенда
Form3 открывается только кнопкой SpeedButton12 (TSpeedButton, без окна): клик — `WM_LBUTTONDOWN/UP` родительской
панели по координатам кнопки (Left/Top из объекта). Строки можно читать из памяти: вектор `DAT_005b1544..1548`
(12 Б: float, int, WideString ptr; длина WideString — dword по ptr−4, в байтах) и форматированно — через
LVM_GETITEMTEXTW у TntListView1 (owner data, текст отдаёт сам процесс). RadioGroup — кнопки-окна (BM_CLICK).

Реализовано: `diffstand.py <файл> --extra` — запускает оригинал только ради Form3 (секунды) и дописывает ключ `extra`
в уже записанный вариант с текущими опциями. Хэндлы контролов берутся из объекта формы (`PTR__Form3` → поле →
`TWinControl.FHandle`, смещение ищется по HWND главного окна). Грабли:
- WM_NOTIFY между процессами не доставляется — клик по заголовку шлётся самому списку как `CN_NOTIFY` (0xBC4E) с
  NMLISTVIEW в памяти процесса;
- ID контрола VCL = его HWND; в WM_COMMAND (CBN_EDITCHANGE для шаблона) в младшее слово идёт только `id & 0xFFFF`,
  иначе портится код уведомления (плавающая ошибка: зависит от значения HWND);
- текст шаблона/фильтров — WM_SETTEXT (у TntEdit сам вызывает OnChange, у комбобокса нужен CBN_EDITCHANGE);
- после каждого расчёта оригинал сам фокусирует строку 0 и вызывает обработчик выбора (`FUN_00444dfc`): без средних
  это прокрутка клавограммы к первому вхождению.
