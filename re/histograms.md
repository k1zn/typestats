# Form4 «Статистические гистограммы»

Порт — `src/core/Histograms`. Открывается кнопкой `Form1.SpeedButton19` (0x4297d4). Отрисовка — тем же движком,
что главный график (`FUN_0043c6bc`, группа `DAT_005b1688`: ось `DAT_005b16b0`, подписи `DAT_005b16b4`,
гистограмма `DAT_005b16bc`) — это UI-этап.

## Страницы

Окно показывает верхнюю страницу стека `DAT_005b1658..165c` (вектор указателей). Страница — объект с vtable
`[0] fill, [1] title, [2] drill(index) → новая страница или 0, [3] dtor`; общие поля: `+4/+8` диапазон записей,
`+0xc` пауза разбиения в мкс, `+0x414` вектор байтов-клавиш столбиков, `+0x440` вектор индексов записей.

| vtable | Страница | fill | title | drill |
|---|---|---|---|---|
| 0x5a0a64 | «Все клавиши» (корень; кнопка «Клавиши») | 0x44c480 | 0x452cd0 | 0x44b7f8 → клавиша |
| 0x5a0a7c | клавиша K (`+0x430`) | 0x44c6e0 | 0x44b9c4 | 0x44c5c0 → сочетание |
| 0x5a0a4c | сочетание P→K (`+0x438`, `+0x430`) | 0x44ca10 | 0x44c838 | 0x44d0dc (переход) |
| 0x5a0690 | «Все пальцы» (кнопка «Пальцы») | 0x44d124 | 0x452bc0 | 0x44d9d4 → палец |
| 0x5a0a34 | палец F (`+0x430`) | 0x44da90 | 0x44e044 | 0x44e0b8 → категория 0..3 |
| 0x5a0a1c / 0a04 / 09ec / 09d4 | категория 0 / 1 / 2 / 3 пальца F (`+0x458`) | 0x44e57c / 0x44ed0c / 0x44f52c / 0x44fe88 | 0x44ec28 / 0x44f448 / 0x44fda4 / 0x45062c | 0x44d0dc |
| 0x5a0678 | список Form3 (кнопка «Дополнительная статистика») | 0x450710 | 0x450a24 | 0x450a98 |

- `FormShow` (0x451308): `fill` верхней страницы, заголовок → `TntLabel1`; масштаб Y = высота / max(1, max значений)
  (`FUN_0043e040`), масштаб X = ширина / число столбиков (все столбики помещаются).
- Двойной клик по столбику: `index = trunc((x − left) / scaleX − offset)`, `drill(index)`; если вернулась страница —
  в стек и `FormShow`. Кнопка «Назад» снимает верхнюю страницу (корень остаётся). Кнопки «Клавиши»/«Пальцы»/
  «Дополнительная статистика» очищают стек и кладут свой корень.
- Recalculate, загрузка файла, смена выделения (если Form4 видима) → `FUN_00451b88`: стек сбрасывается до корня,
  `FormShow`. Расчёт Form3 при флаге `Form3+0x360` (корень — список Form3) → `TForm4::FormShow`.

## Общая часть (0x44b91c)

Диапазон элементов `[b, e)` — `FUN_004252fc` (как у основной статистики); записи:
`recB = at(mapRec, lowerBound(mapElem, b))`, `recE = at(mapRec, lowerBound(mapElem, e))`; `split = UpDown1 · 1000` мкс.

Все расчёты идут по **записям** `g_rec[recB..recE)` (после Recalculate: нормализованы, бит 0x100 «стёрто» выставлен):
```
acc (u64) = 0
для каждой записи: acc += dt
  отпускание (flags & 0x2000) — дальше не смотрим
  нажатие: key = flags & 0xff (скан-код), finger = zones[flags & 0x7f] (0..7, 8 — прочие)
           «годное» = acc < split и !(flags & 0x100)
           … обработка страницы …
           acc = 0
```
Константа пересчёта в мс — extended 0.001 (0x44d0d0 и копии).

## Клавиши

- **Все клавиши** (0x44c480): годное нажатие → `sum[key] = float(acc + sum[key])` (мкс), `cnt[key]++`.
- **Клавиша K** (0x44c6e0): то же, но только для нажатий `key == K`, и копится по **предыдущей** клавише:
  `sum[prev] += acc`, `cnt[prev]++`. `prev` — клавиша предыдущего нажатия (любого, в т.ч. негодного), начальное 0.
- Вывод обоих (0x44bc8c): `avg[i] = float(sum[i] / (cnt[i]·1000))` (деление в extended) при `cnt ≠ 0`; затем столбики
  по убыванию avg: каждый раз берётся максимум (при равенстве — меньший код), пока он `> 0.01` (double 0x44c478).
  Столбик: значение avg (мс), подпись — имя клавиши, счётчик `cnt` (вектор `DAT_005b1670`), код клавиши (`+0x414`).
- **Сочетание P→K** (0x44ca10): каждое годное нажатие K сразу после нажатия P — отдельный столбик
  `float(0.001 · acc)`, подпись — порядковый номер «1», «2», …; в `+0x440` — индекс записи нажатия P.
  Счётчиков нет. Двойной клик (0x44d0dc): клавограмма прокручивается к элементу
  `at(mapElem, lowerBound(mapRec, rec))` (`FUN_004050cc`).
- Имя клавиши (0x448fe8): `vk = MapVirtualKeyEx(scan, 3, hkl)`, символ — `ToUnicodeEx` при **текущей раскладке окна**
  (Ctrl/Alt сброшены), дальше `KeyDisplayName(scan | vk<<16 [| 0x8000 без символа], ch)`. То есть подписи зависят
  от раскладки на момент показа, а не от записи. В порту подпись берётся из самой записи (самый частый символ
  клавиши) — сознательное отличие. 0x44bb9c дополнительно заменяет `"\r"` на `[Enter]`.
- Заголовки: «Все клавиши» (`DAT_0058e2bc`); «Клавиша X» (`DAT_0058e270` + " " + имя; имя из одного символа берётся
  в скобки: «Клавиша [а]»); «Длительности сочетаний [PK]» (`DAT_0058e274` + " [" + имя P + имя K + "]").

## Пальцы

- **Все пальцы** (0x44d124): 9 столбиков (пальцы 0..7 и «прочие»): годное нажатие → `cnt[f]++`,
  `sum[f] = float(0.001·acc + sum[f])`; значение `sum/cnt` (float) или 0. Подписи — `DAT_0058e298[9]`:
  ЛМ, ЛБ, ЛС, ЛУ, ПУ, ПС, ПБ, ПМ, Прочие. Счётчики — `cnt`.
- **Палец F** (0x44da90): 4 столбика-категории. Состояние `prevKey = 0, prevFinger = −1, prevHand = −1`;
  `hand = f < 4 ? 0 : (f == 8 ? −1 : 1)`.
  ```
  годное нажатие: cat = key == prevKey ? 0 : f == prevFinger ? 1 : hand == prevHand ? 2 : 3
                  prev* = текущие;  если f == F: cnt[cat]++, sum[cat] += 0.001·acc
  негодное:       prev* сбрасываются в начальные
  ```
  Значение `sum/cnt` или 0; подписи — `DAT_0058e278[4]`: «Клавиша», «Палец», «Рука», «Прочее».
- **Категория пальца F** — по столбику на каждое годное нажатие пальцем F, `float(0.001·acc)`; здесь `prev*`
  обновляются на **каждом** нажатии (и негодном), начальные те же:
  | № | условие | подпись | заголовок (`DAT_0058e288..294`) |
  |---|---|---|---|
  | 0 | `key == prevKey` | имя клавиши | Двойное нажатие на клавишу |
  | 1 | `f == prevFinger` и `key ≠ prevKey` | имя prev + имя key | Разные клавиши |
  | 2 | `f ≠ prevFinger` и `hand == prevHand` | то же | Та же рука (другой палец) |
  | 3 | `hand ≠ prevHand` | то же | Другая рука |
  В `+0x440` — индекс записи предыдущего нажатия; двойной клик — переход, как у сочетаний.
  (Сумма по категориям на странице пальца может не совпадать с числом столбиков здесь — из-за разного сброса prev.)
- Заголовки: «Все пальцы» (`DAT_0058e2c0`); палец — полное имя (`0x59dbdc[9]`: Левый мизинец, Левый безымянный,
  Левый средний, Левый указательный, Правый указательный, Правый средний, Правый безымянный, Правый мизинец,
  Остальные клавиши); категория — «<заголовок категории> - <полное имя пальца>».

## Список Form3 (0x450710)

Столбики — строки списка Form3 в порядке показа: значение = скорость (`Item.Data`), подпись = текст. Счётчиков нет.
Заголовок — Hint кнопки Form1.SpeedButton12 («Дополнительная статистика»). Двойной клик — выбор строки в Form3
(`FUN_00444dfc`). Ставит `Form3+0x360 = 1`: каждый расчёт Form3 обновляет гистограмму.

## Подсказка (PaintBox1MouseMove, 0x451444)

При зажатой кнопке мыши над столбиком: `FloatToStrF(значение, ffFixed, 8, 3)` + (если есть счётчик) `" (" + cnt + ")"`
+ `" "` + подпись (`"\r"` → `[Enter]`).

## Для стенда

Значения — `*(DAT_005b16b8) + 0x24/0x28` (vector<float>), подписи — `*(DAT_005b16bc) + 0x40` (вектор WideString),
счётчики — `DAT_005b1670..1674` (int), верхняя страница — `DAT_005b165c[-1]`. Кнопки Form4 — TSpeedButton на Panel1
(клик по панели); двойной клик по столбику: записать x в `DAT_0059e694` и послать форме `WM_LBUTTONDBLCLK` в точку
PaintBox1.
