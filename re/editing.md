# Правка записи и копирование текста

Порт — `src/core/Editing` (логика, тесты `tst_editing`), обработчики — в `src/ui/MainWindow`.

Все операции работают с вектором записей `g_recBegin` **после нормализации** Recalculate (индексы записей — те же, что в
маппингах). Порт перед правкой заменяет записи документа нормализованной копией `TextModel::records`.

Маппинги: `DAT_005b1018` — позиции текста, `1030` — элементы, `1048` — записи клавограммы, `1060` — записи (в порту —
`TextModel::anchors`). `lb(map, x)` = `FUN_0040382c` (lower_bound → индекс якоря), `at(map, i)` = `FUN_0040373c`.

## Доступность команд

`Memo4SelectionChange` (0x418e2c): есть выделение → видны пункты меню «Удалить» (N4), «Пометить» (N1), включены кнопки
«Удалить (Del)» (SpeedButton10) и «Сохранить блок» (SpeedButton27); нет — скрыты/выключены.

`Memo4KeyDown` (0x419718): без модификаторов Del → удалить, Ins → пометить; с Ctrl: Ins или C при выделении →
«Копировать», A → выделить всё; прочие клавиши, кроме навигации (0x21..0x28), гасятся.

`Memo4MouseMove` (0x41a21c): запись под мышью `r = at(1060, lb(1018, charFromPos))`.
- Символ под мышью — «‡»: подсказка `FloatToStrF(пауза, ffFixed, 8, 3) + " " + «мс»` — время между записями клавограммы
  по обе стороны разделителя.
- Иначе `k = labelStart(r)`. `k ≥ 0`: пункты «Редактировать метку» (N2) и «Удалить метку» (N3) видны, цель — `k`,
  подсказка — комментарий записи `k`. `k < 0`: пункты видны, только если у записи `r` есть комментарий (цель — `r`).

## Диапазон записей выделения (`FUN_004254b4`)

Нет выделения → `{0, 0}`. Иначе **копия записей сохраняется для отмены** и
`from = a > 0 ? at(1060, a − 1) + 1 : 0`, где `a = lb(1018, SelStart)`;
`to = SelStart + SelLength < длина текста ? at(1060, lb(1018, SelStart + SelLength)) : число записей`.

## «Удалить» (SpeedButton4Click 0x419a08)

`acc` — накопленное `dt`. В `[from, to)`: нажатие — выбрасывается, его VK помечается; отпускание клавиши, чьё нажатие
не выброшено (нажата до диапазона), остаётся с `dt = acc`; отпускание выброшенного нажатия выбрасывается. После `to`:
нажатия и отпускания невыброшенных клавиш остаются (`dt = acc`), отпускания выброшенных — нет. Время выброшенных
записей, таким образом, переходит к следующей оставленной: общее время не меняется. Затем `Recalculate(0)`.

## «Удалить нетекстовые клавиши» (SpeedButton18Click 0x428dd4)

Копия для отмены; элементы `[b, e)` — как для статистики (`FUN_004252fc`: выделение / весь текст / фрагмент), записи
`[at(1060, lb(1030, b)), at(1060, lb(1030, e)))`. В диапазоне нажатие остаётся, если имя клавиши — один символ,
`[LShift]`, `[RShift]` или `[BackSpace]`; иначе выбрасывается вместе со своим отпусканием. Отпускание Shift, под которым
ничего не осталось нажатым (он был последним оставленным нажатием), выбрасывается **вместе с нажатием** этого Shift.
После диапазона остаются все нажатия; отпускания — по тем же правилам. Время — как при удалении.

## «Отменить» (SpeedButton14Click 0x428a94)

Один уровень: текущий вектор записей и копия (`DAT_005b1000`) меняются местами, `Recalculate(1)`; повтор возвращает
правку. Копию делают «Удалить», «Удалить нетекстовые клавиши» (и, побочно, «Сохранить блок»).

## Метки

`labelStart(i)` (`FUN_00419e58`): идём от `i` назад, пока запись помечена (0x200) или это отпускание; ответ — самая
ранняя помеченная из пройденных, −1 если таких нет. Запись 0 проверяется, только если с неё начали.

«Пометить» (SpeedButton13Click 0x419ed4), записи `[rb, re) = [at(1060, lb(1018, SelStart)), at(1060, lb(1018, SelEnd)))`:
- `rb < re`: нажатиям ставится 0x200; их комментарии стираются, последний запоминается; комментарий первого нажатия
  после `re` тоже забирается (и стирается). `k = labelStart(re − 1)`; если `k > 0` — комментарий записи `k` = запомненный,
  и открывается `InputQuery(«Текстовая метка», «Текст метки»)` для него. `Recalculate(0)` с сохранением прокрутки текста.
- нет выделения: `InputQuery` для комментария записи `rb`; при OK — `Recalculate(0)`.

«Редактировать метку» (N2Click): `InputQuery` для записи-цели. «Удалить метку» (N3Click): `k = labelStart(цель)`;
`k < 0` — стереть комментарий цели; иначе от `k` вперёд по нажатиям: стереть комментарий, снять 0x200; остановиться на
первом непомеченном нажатии (его комментарий тоже стирается).

На время `InputQuery` хук снимается.

## Копирование

Элементы `[b, e)` — `FUN_004252fc`. Имя «█» (стёртый пробел) при копировании снова пробел.
- «Копировать» (N5Click 0x424754): имена подряд. «Копировать без ошибок» (N6Click 0x424868): без стёртых элементов.
- «Копировать с тегами» (N15Click 0x42a718), настройки Form8 `CopyBlock1..3` (цвет / зачёркивание / следующий символ,
  все включены): перед серией стёртых `[color="#ff4444"]` и `[s]`, после — `[/s]` и `[/color]`; первый элемент после
  серии — `[color="#aa4444"]…[/color]`. «█» → пробел, только если включено зачёркивание.

## Сохранение

`SaveTsf(form, block)` (0x415480): сначала «Свойства файла» (Form2: автор, дата, описание). Для загруженного файла при
полном сохранении автор только для чтения, свойства прежние; иначе автор — из настройки (`autor`), дата —
`DateTimeToStr(Now)`, описание пустое; изменённый автор нового файла запоминается в настройках. `block`: записи
`FUN_004254b4` (нет выделения — все); заголовок окна и имя файла не меняются, видео не прикладывается.
Подпись — если `g_fileClean` (после «Очистить» и открытия журнала — да, после открытия .tsf — по проверке подписи).
