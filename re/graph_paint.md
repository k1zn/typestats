## Объекты

`DAT_005b13bc` — вектор «панелей» одного PaintBox; у каждой свой TBitmap. База (vtable `0x59b50c`, ctor `0x43a0e4`):
`+4/+8` мышь (в координатах панели), `+0xc/+0xd/+0xe` зажаты правая/левая/средняя кнопки, `+0x10..+0x1c`

### Масштабы (`FUN_00405b34`; после Recalculate и при изменении Panel9 — через `ApplicationEvents1Idle`)

`FUN_00439c5c(series, min, max, &outMin, &outMax, round)`; `min`/`max` = `StrToIntDef(текст комбобокса, −1)`
(«Авто» → −1):
```
по значениям v ≥ −0.1: lo = min, hi = max; hi = min(hi, 1200)
outMin = trunc(lo); outMax = trunc(ceil(hi))
если round («Авто с округлением»): s = hi > 100 ? 100 : 10; outMax = ((outMax − 1) / s + 1) · s; outMin = (outMin / s) · s
если значений нет: outMin = max(min, 0)… (min < 0 → 0), outMax = max < 0 ? 100 : max; scale/offset не меняются
min < 0 → min = outMin; max < 0 → max = outMax
offset = min; scale = max > min ? 100 / (max − min) : 100
```
Второй пункт списка каждого комбобокса заменяется на найденное авто-значение.
- скорости (0–3): по «Средней скорости» (1), `SpeedYmin` (0) / `SpeedYmax` (−1 = Авто);
- ритмичности (4, 5): по «Средней ритмичности» (5), `RythmYmin` (0) / `RythmYmax` (100);
- аритмия (6): `scale = 0.25`, `offset = −100` (−100 % … +300 %);
- длительности (7): `FUN_004398a8(s, 100, 10)`: `scale = 40 / ((trunc(mean) / 100 + 1) · 100)`, `offset = 0`;
  `mean` — среднее значений серии > −1000 (`FUN_00439c10`, считается в конце Recalculate).

Там же, если в серии 1 больше одного значения: `zoomY = 0.01 · H`, `scrollX = 1`, `offsY = 0` (вид сбрасывается).
При старте: `zoomY = 0.01 · H · 0.9`, `zoomX = 8`.

## Отрисовка графика (`0x43ad84`)

`W`, `H` — размеры панели графика. `round(v)` = `FUN_0043986c`: `trunc(v ± 0.5)`.

1. Фон `RGB(255,255,220)`. Нет серий — выход.
2. `x1 = x(visFrom)`, `x2 = x(visTo)`; полоса `[x1, x2) × H` цветом `RGB(255,255,180)` — то, что на клавограмме.
3. Шрифт строки текста: наибольший `k = 10..0`, для которого `charW[k] < zoomX` (`charW[k]` — ширина «1» Courier New
   `k + 8` pt); размер `k + 8`. Нет такого — строка текста пустая и нет вертикальной сетки.
4. `cy = TextHeight("000") / 2` шрифтом оси.
5. Перо psDot `RGB(175,175,175)`. Вертикали по пробелам: для `i` от `max(0, floor(−scrollX))`, если имя элемента
   `" "`: `x = floor((i + scrollX + 0.5) · zoomX + 0.5)`; `x ≥ W` — стоп; линия на всю высоту.
6. Горизонтальная сетка и подписи оси. Серии оси `A = {1, 5, 7 если серия 7 видима, иначе 6}`; ведущая `m = A[режим]`.
   ```
   steps = {1, 2, 5, 10, 20, 50, 100, 200, 500}
   k = первый из 0..7, для которого steps[k] · scale_m > 7·cy / zoomY; иначе 8
   stepU = steps[k] · scale_m                                  // шаг в единицах (float)
   a = round(−offsY / stepU) · stepU
   v = round(offset_m + a / scale_m)                           // значение ведущей серии у нижнего края
   d = (v / steps[k]) · steps[k] − v; если v % steps[k] ≠ 0: d += v > 0 ? steps[k] : −steps[k]
   a += scale_m · d                                            // первая линия на кратном шагу значении
   top = H / zoomY − offsY
   знаки для серии j из A: r = stepU / scale_j; |r| < 0.21 → 2; иначе |r| < 4 и |r − round(r)| > 0.1 → 1; иначе 0
   пока a < top:  py = (offsY + a) · zoomY
       py > −2:   py > 0.1 → пунктирная горизонталь y = trunc(H − py) на всю ширину
                  для idx = 0..2, j = A[idx]: текст FloatToStrF(a / scale_j + offset_j, ffFixed, 15, знаки[idx])
                  цветом серии j на панели оси: x = axisW − TextWidth − 3, y = trunc(H − py − (3 − 2·idx) · cy)
       a += stepU
   ```
   То есть у каждой линии три подписи одна под другой: скорость, ритмичность, гистограмма.
7. Перо сплошное. Серии по порядку `draw(bitmap, scrollX, offsY, zoomX, zoomY)`, только с `visible` и `inLegend`;
   первый индекс `i0 = max(0, floor(−scrollX))`:
   - линия (`0x439ef4`): точки `(x(i), H − trunc(((v − offset) · scale + offsY) · zoomY) − 1)`; маркер фрагмента
     (`v < 0`) рвёт ломаную; после первой точки с `x ≥ W` — стоп;
   - гистограмма длительностей (`0x439920`): вертикаль `x(i)` от `H − trunc(v · zoomY · scale + offsY · zoomY) − 1` до `H`;
   - гистограмма аритмии (`0x439a5c`): база `y0 = H − round(offsY · zoomY + 100 · zoomY · scale)` (значение 0 %);
     для `v ≥ −1000`: `x = round((i + scrollX) · zoomX)`, вертикаль от
     `H − round(offsY · zoomY + (v − offset) · zoomY · scale) − 1` до `y0`; в конце горизонталь `y0` на всю ширину,
     если `y0 > 0`.
8. Границы фрагментов (`0x439dc0`): где серия 0 отрицательна (маркер) — чёрная вертикаль 2 px на `x(i)`.
9. Курсор (если `+0xa1 == 0`): чёрная вертикаль на `x` мыши.
10. Серые `RGB(128,128,128)` вертикали на `x1` и `x2`.
11. Линейка (если `rulerY > −1e6`): `y = H − round((rulerY + offsY) · zoomY)`; три строки
    `FloatToStrF(rulerY / scale_j + offset_j, ffFixed, 7, 1)` для `j` из `A`; `w` — наибольшая ширина, `th` — высота
    строки; плашка `Rectangle(W − 6 − w, y − 3·th/2, W + 1, …)` высотой `3·th + 3`, заливка `RGB(180,255,180)`;
    строки цветами серий на `left + 2`, `top + 1 + idx · th`; чёрная горизонталь от `0` до `left` на `y`.
12. Строка текста (если шрифт найден): для `i` от `i0`: `x = trunc(floor((i + scrollX + 0.5) · zoomX + 0.5) −
    charW[k] / 2)`; `x ≥ W` — стоп; цвет: injected — синий, стёртый — красный, иначе чёрный; односимвольное имя, кроме
    `"\r"`, — `TextOutW(x, 1)`; иначе символ шрифта Symbol, как на клавиатуре клавограммы (`FUN_0043967c`: ⇑ ← ⇐ ↵),
    а для прочих длинных имён — символ 0x80 (в порту — `·`).

Ось (`0x43cb0c`): заливка `RGB(240,240,32)`, чёрные вертикали на `x = 0` и `x = axisW − 1`.
Строка текста (`0x43ca8c`): заливка `RGB(240,240,32)`, чёрная горизонталь по верхнему краю.

## Мышь

`PaintBox1MouseDown` → `FUN_0043c730` отдаёт номер панели под мышью: ось (1) + правая кнопка — `PopupMenu2`;
график (3) + левая кнопка — клавограмма прокручивается к элементу под мышью:
`scroll = (tDraw(klavOfElement(e)) − 100 µs) · 0.001`, `e = elementAt(x)`.

`elementAt(x)` (`FUN_0043ad40`): `v = x / zoomX − scrollX + 0.5`; `v < 0.5` → −1, иначе `trunc(v)`.

Нажатие на графике (`0x43c0c8`), правая кнопка: внутри плашки линейки — линейка убирается; иначе, если с прошлого
правого клика < 500 мс, — линейка включается и следует за мышью (`rulerY = (H − 1 − y) / zoomY − offsY`); одиночный
правый клик останавливает её.

Движение (`0x43c264`, `dx`, `dy` — смещение мыши):
- правая (без левой): `zoomX += dx · zoomX / 100` (0.5..100); если не «Зафиксировать» — `zoomY −= dy · zoomY / 100`
  (0.4..50); `scrollX = (visFrom + scrollX_old − 1) · zoomX_old / zoomX + 1 − visFrom`;
- левая: `scrollX += dx / zoomX`; если не «Зафиксировать» — `offsY −= dy / zoomY`;
- средняя: `scrollX += dx · 50 / zoomX`;
- затем `scrollX` ограничивается: `q = W / 4` (целое); `[min(1, q / zoomX − n), 3·q / zoomX]`, `n` — число элементов.

Левая + правая (`PaintBox1MouseMove`, до движка): масштаб клавограммы подбирается так, чтобы на ней помещалось от
`visFrom` до элемента под мышью: `d = (tDraw(k2) − 100) · 0.001 − tDraw(k1) · 0.001`; `zoom = d > 0.01 ? Wклав / d : 300`,
в пределах 0.04..300.

После движения с любой зажатой кнопкой: параметры ScrollBar1 (`FUN_0040687c` → `FUN_0043c170`), синхронизация
(`FUN_0043a918(model, 1)`), `ScrollBar1.Position = trunc(1 − scrollX)`, подсветка текста, ListView1.

Двойной клик (`0x43c0a4`): переключить курсор (`+0xa1`); пока курсор показан, легенда показывает значения серий
под ним. Колесо над Panel1/ScrollBar1: позиция ScrollBar1 ∓ SmallChange.

## ScrollBar1 и синхронизация с клавограммой

`FUN_0043c170`: `q = W / 4`; `lo = trunc(−3·q / zoomX)`; `hi = max(0, trunc(n − q / zoomX))`; `page = trunc(W / zoomX)`;
ScrollBar: `Min = lo + 1`, `Max = hi + page`, `SmallChange = max(1, page / 20)`, `LargeChange = PageSize = page`.
`ScrollBar1Scroll`: `pos ≤ Max − PageSize`; `scrollX = 1 − pos`, затем синхронизация «график → клавограмма».

`FUN_0043a918(model, graphLeads)`:
```
right = trunc(−scrollX + W / zoomX); delta = 0; lo = visFrom
если right < visTo: delta = right − visTo; lo += delta      // видимый участок ушёл за правый край
если −scrollX ≥ lo: delta = trunc(−scrollX − visFrom)       // … за левый
delta == 0 → false
graphLeads:  visFrom += delta; visTo += delta; visFrom = max(visFrom, 0)
             → вызывающий ставит клавограмме scroll = tDraw(klavOfElement(visFrom)) · 0.001
иначе:       delta < 0 → scrollX = W / zoomX − visTo;  иначе scrollX = −visFrom
             → вызывающий ставит ScrollBar1.Position = trunc(1 − scrollX)
```
`FUN_00424e64` (после любого движения клавограммы): записи клавограммы под виджетом → элементы → `visFrom/visTo`
(`FUN_0043a8fc`), затем `FUN_0043a918(model, 0)`.

## Легенда (`DAT_005b1414`, Panel2)

Panel2 — плавающая панель в главном окне: фон `RGB(255,255,200)`, рамка; заголовок Panel16 17 px («Легенда», белый
жирный на clActiveCaption, таскает панель мышью — `FUN_004288c8`, в пределах клиентской области) с красной кнопкой
закрытия Panel17 (Webdings «r»). Закрытие (Panel17Click 0x42889c): панель скрыта, в меню появляется «Показать
легенду» (N8), кнопка SpeedButton17 включается. Открытие (N8Click 0x42872c, и кнопкой): панель видна, N8 скрыт,
SpeedButton17 **выключена** — кнопка только открывает, закрывает красная кнопка. Ключи пресета: `LegendVisible` (1), `LegendWinLeft`, `LegendWinTop`, `LegendMinimized` (0).

Шрифт Courier New 8 pt; высота строки `rowH = TextHeight("1q")`; размер PaintBox2: `38 · TextWidth("1") × 8 · rowH`,
в свёрнутом виде (двойной клик по заголовку) ширина `9 · TextWidth("1")`.

Отрисовка (`0x43cf64`): фон `RGB(255,255,200)`; для серий с `inLegend` строка `имя` (в свёрнутом виде — первые 8
символов) `+ " "`; если курсор показан и `e = elementAt(мышь)` в пределах серии и `v > −1000` — (в свёрнутом виде имя
заменяется на пустую строку) `+ FloatToStrF(v, ffFixed, 15, 2)`; цвет серии, жирный — если серия видима;
`TextOut(0, rowH · строка)`.

Клик (`0x43ce0c`): строка `(y − 2) / rowH` переключает видимость серии; гистограммы 6 и 7 взаимно исключают друг
друга (включение одной выключает другую). В свёрнутом виде подсказка — полное имя серии без двоеточия.

## «Настройка оси Y» (Panel9)

«Мин» — редактируемые комбобоксы (`Авто` / число): ComboBox5/ComboBox2 — скорость макс/мин, ComboBox6/ComboBox3 —

радио «Скорость» / «Ритмичность» / «Гистограмма» (`N9Click`: режим оси `+0xdc`).

## «Свёрнутый» график (Panel1 ниже 100 px)

`Panel1CanResize` (0x425000): новая высота < 100 → `DAT_0058e1d5 = 1`, легенда (Panel2) прячется, от Panel1 остаётся
только Panel4 со ScrollBar1 (22 px), клавограмма (Panel7) забирает освободившееся место. Высота ≥ 100 → режим
снимается, легенда возвращается, если не была закрыта (пункт N8 не виден).

В свёрнутом режиме ScrollBar1 прокручивает клавограмму (`FUN_0040687c`, ветка `DAT_0058e1d5`), всё в мс,
`W` — ширина клавограммы, `z` — её масштаб (px/мс):
```
page = W / z;  left = −W / (4·z);  end = max(0, tDraw(последняя запись) · 0.001 + left)
SmallChange = max(1, trunc(0.05 · page)); Min = trunc(3 · left); Max = trunc(end + page)
LargeChange = PageSize = trunc(page);    Position = trunc(scrollMs клавограммы)
```
`ScrollBar1Scroll`: `scrollMs = pos` (pos ≤ Max − PageSize), затем подсветка текста, ListView1, перерисовка. Любое
движение клавограммы (`FUN_00424e64`) ставит `Position = trunc(scrollMs)`; изменение её масштаба перестраивает
параметры полосы.

Порт: `MainWindow::graphPaneResized` (по `splitterMoved` и после загрузки размеров) и ветка в `syncGraphScrollBar`.
