# Основная статистика (ListView2 главного окна)

## Где что лежит

| Адрес | Что это |
|---|---|
| 0x41c794 | **не статистика**, а `LoadLanguage(Form1, name)`: `TIniFile(<папка exe>\<name>.lng)`, секция `Main`, ключи-номера → подписи всех контролов. Параметр — `DAT_005b1464` (имя языка из реестра `Language`). См. раздел «Локализация» ниже |
| **0x4255a8** | **расчёт основной статистики** (`ShowMainStats(Form1)`) |
| 0x404a78 | перестроить строки ListView2: по одной на каждый отмеченный пункт `Form8.CheckListBox1`, значения пустые |
| 0x40cdcc | очистить колонку «Значение» |
| 0x4252fc | диапазон элементов текста для статистики `[b, e)` |
| 0x438304 | скорость «spm» и время удержания по записям клавограммы |
| 0x40332c | форматирование времени `FormatTime(ms, digits)` |
| 0x406a90 | сохранение пресета (в т.ч. `MainOption<i>` = галочки CheckListBox1) |

Список параметров — `Form8.CheckListBox1.Items` (17 шт.). В ListView2 показываются только
отмеченные, в том же порядке. Галочки хранятся в пресете как `MainOption0`…`MainOption16`
(читает `FUN_0041ab08`, по умолчанию 1 — показываются все 17).

**Сверено с оригиналом** (`re/scripts/diffstand.py`, `tests/tst_orig.cpp`): все 17 строк на golden-файлах
при пяти наборах опций, со случайными выделениями и курсором без выделения — совпадают побайтно.

Результат каждой строки сначала пишется в глобальный массив `AnsiString DAT_005b1354[17]`
(0x5b1354…0x5b1394, шаг 4), а потом отмеченные строки копируются в ListView2 через
`LVM_SETITEMTEXT` (0x1074). Пересчёт пропускается, если `[b, e)` не изменился с прошлого раза
(кэш `DAT_0058e1b0/b4`). В конце, если открыты, пересчитываются Form3 (0x43ff3c) и Form4 (0x451b88).

## Входные данные (строит Recalculate 0x40ce40)

**Текстовая модель** `DAT_005b1410`, по одному *элементу* на каждое нажатие, попавшее в текст:
- `+0x40` `vector<WideString> text[i]` — `KeyDisplayName(flags)`:
  - символ;
  - `\r` для Enter;
  - `[BackSpace]`, `[LCtrl]`, `[Ctrl+…]` и т.п. (всё длиннее 1 символа берётся в скобки).
  «Символом» считается элемент с `len(text[i]) == 1`, в том числе Enter.
- `+0x58` `vector<bool> erased[i]` = флаг записи `0x100`: символ потом стёрт BackSpace/Ctrl+BackSpace
  (разметка ниже).
- `+0x78` `vector<bool>` = флаг записи `0x1000`. Используется только для мёртвой метрики, см. «Особенности».

**Паузы** `DAT_005b1408 +0x24`: `vector<float> pause[i]`, мс:
- `pause[i] = (float)(0.001 · Σdt_µs)` — сумма dt всех записей (включая отпускания и отфильтрованные
  клавиши) от предыдущего элемента до этого;
- у первого нажатия фрагмента (после паузы > «Паузы разбиения», флаг записи `0x40000000`)
  `pause = −2147483648.0` (`0xCF000000`). Это маркер начала фрагмента, в статистике он отсекается
  условием `p > −0.1`.

**Клавограмма** `DAT_005b1348`: `vector` записей по 40 байт (`+0x30/+0x34`):

| смещение | поле |
|---|---|
| +0x00 | u64 абсолютное время, мкс |
| +0x08 | u64 время от предыдущего события |
| +0x10 | u64 время для отрисовки: пауза между фрагментами ужата до 200 мс |
| +0x18 | flags |
| +0x1c | ch |
| +0x20 | u8: 1 — нажатие, 0 — отпускание |

Отпускание добавляется, только если клавиша есть в списке нажатых.

**Маппинги** (отсортированные `vector<int>`):
- `DAT_005b1018` — позиция в RichEdit → элемент;
- `DAT_005b1030` — элемент текста;
- `DAT_005b1048` — индекс записи клавограммы;
- `DAT_005b1060` — индекс сырой записи.

`FUN_0040382c(v, x)` = `lower_bound(v, x) − v.begin()`;
`FUN_0040373c(v, i)` = `i < v.size() ? v[i] : v.back() + 1` (для пустого — 0).

## Диапазон `[b, e)` (0x4252fc)
- Есть выделение в RichEdit (`Memo4.SelLength ≠ 0`): `b, e` — элементы начала и конца выделения
  (через `DAT_005b1018` → `DAT_005b1030`).
- Нет выделения, `CheckBox3` («Разбивать по паузам») выключен: `b = 0`, `e = pause.size()`.
- Нет выделения, `CheckBox3` включён: текущий фрагмент вокруг курсора. От элемента под курсором
  `b` идёт назад, пока `pause[b] ≥ 0` (останавливается на маркере начала фрагмента или на 0).
  `e` идёт вперёд от `cursor+1`, пока `pause[e] ≥ 0`.

## Основной цикл

```
chars = 0            // edi: символов (len==1) в диапазоне
erasedN = 0          // local_208: элементов с erased
erasedSeries = 0     // local_20c: серий подряд идущих стёртых (по символам)
prevErased = false   // local_20d: erased предыдущего СИМВОЛА
sumAll = sumClean = 0.0            // double, мс
minP = 1e20; maxP = 0
nAll = nOk = nClean = 0            // local_23c / local_240 / local_244
accAll = accClean = 0.0            // накопители интервалов
intervalsAll = [], intervalsClean = []  // vector<float>
run = maxRun = 0                   // local_248 / local_24c

for i in [b, e):
    single = len(text[i]) == 1
    if chars != 0:                          // пауза первого символа диапазона не считается
        p = pause[i] (0, если i вне вектора)
        if p > -0.1:                        // отсекает маркер начала фрагмента
            minP = min(minP, p); maxP = max(maxP, p)
            sumAll += p; accAll += p
            if single:
                nAll++
                intervalsAll.push(float(accAll)); accAll = 0
            if not erased[i]:
                if single: nOk++
                // local_220 += p — сумма считается, но нигде не используется
                if not erased[i-1] and not prevErased:
                    sumClean += p; accClean += p
                    if single:
                        nClean++
                        intervalsClean.push(float(accClean)); accClean = 0
    if erased[i]:
        erasedN++
        if not prevErased: erasedSeries++
    if single:
        prevErased = erased[i]
        chars++
        if not erased[i]: run++
        else: maxRun = max(maxRun, run); run = 0
maxRun = max(maxRun, run)
if minP > 1e19: minP = 0
```

- Паузы не-символов (BackSpace, модификаторы) входят в `sumAll` и прибавляются к интервалу следующего символа.
- «Чистый» интервал берётся, только если ни этот элемент, ни предыдущий элемент, ни предыдущий
  символ не стёрты.
- `erased[i-1]` при `i = 0` читает бит −1 (в оригинале это чтение за пределами массива). На практике
  до этого места не доходит, потому что при `i = b` ещё `chars = 0`.

## Производные величины

```
avgAll   = nAll   ? sumAll/nAll     : 0     // local_454
avgClean = nClean ? sumClean/nClean : 1.0   // local_45c (по умолчанию 1.0, не 0!)

arrAll   = Σ|x − avgAll|   по intervalsAll   // fabs = 0x55c3d8
if intervalsAll.size() != 0 and avgAll > 0.001:
    arrAll /= intervalsAll.size() · avgAll · 0.01
arrClean = 0
if intervalsClean.size() != 0:
    arrClean = Σ|x − avgClean|
    if avgClean > 0.01: arrClean /= intervalsClean.size() · avgClean · 0.01

// скорости, зн/мин; вариант с +1 — основной, без +1 — в скобках
if nOk  && sumAll   > 0.01:  net  = (nOk+1)·60000/sumAll,             net0  = nOk·60000/sumAll
if nAll && sumAll   > 0.01:  gro  = (nAll+1)·60000/sumAll,            gro0  = nAll·60000/sumAll
k = nAll + erasedN
if k    && sumAll   > 0.01:  groP = (k+1)·60000/sumAll,               groP0 = k·60000/sumAll
if nClean && sumClean > 0.01: groS = (nClean+1)·60000/sumClean,       groS0 = nClean·60000/sumClean
(иначе 0)

corrPct   = chars ? erasedN·100/chars      : 0
seriesPct = chars ? erasedSeries·100/chars : 0
maxRunPct = chars ? maxRun·100/chars       : 0
loss = groS0 > 1.0 ? (groS0 − net0)·100 / groS : 0
```

Проценты и `loss` хранятся во float, скорости — в double. `loss` делится на `groS` с +1,
а вычитаются значения без +1. Так в оригинале, воспроизводим как есть.

### Скорость spm и время удержания (0x438304)
Аргументы:
- `rb = DAT_005b1048[lower_bound(DAT_005b1030, b)]`, `re` — то же для `e`;
- `split = CheckBox3 ? 0 : UpDown1·1000` мкс, `0` → 50 000 000.

```
pressT[256] = −1 (u64), n = 0, T = 0 (u64 мкс), hold = 0, holdN = 0
prev = 0xFFFFFFFF80000001 (u64; «очень давно»), pending = 0, shiftF = deadF = false
for i from rb to the end of the klavogram:
    r = rec[i], vk = (r.flags>>16)&0xFF
    if r is a release:
        if pressT[vk] ≥ 0:                    // старший dword ≥ 0
            hold += r.t − pressT[vk]; holdN++ // pressT не сбрасывается
            if pending: pending--; if i ≥ re and pending == 0: break
        if vk in (0xA0, 0xA1): shiftF = false
    else:
        pressT[vk] = r.t
        if i < re:
            dt = r.t − prev
            counted = !(r.flags & 0x40000000) and dt < split
            if counted: T += dt
            if vk == 8 or (r.flags & 0x100):
                if (r.flags & 0x100) and n and (shiftF or deadF): n--; shiftF = deadF = false
            else:
                if counted: n++
                shiftF = vk in (0xA0, 0xA1)
                deadF  = r.flags & 0x20000000
            pending++; prev = r.t
holdAvg = holdN ? hold / holdN : 0          // целочисленное деление int64, мкс
spm  = T ? (n+1)·6e7 / T : 0 ;  spm0 = T ? n·6e7 / T : 0
```

- `n` считает все нажатия, кроме BackSpace и стёртых. Модификаторы тоже считаются.
- Если сразу за Shift или мёртвой клавишей идёт стёртый символ, Shift/мёртвая тоже снимаются.

## Строки вывода

Числа выводятся через `FloatToStrF(x, ffFixed, 15, d)`: десятичный разделитель системной локали,
без разделителя тысяч. `U` — подпись `Form1.Label2` («мс», из .lng). Строки ниже — литералы из
кода, их не переводят.

| # | Параметр | Формат |
|---|---|---|
| 0 | Символов | `{chars} ({chars − erasedN})` |
| 1 | Общее время | `FormatTime(trunc(sumAll), 3)` |
| 2 | min пауза | `{minP:.3} U` |
| 3 | max пауза | `{maxP:.3} U` |
| 4 | Средняя пауза | `{avgAll:.3} U` |
| 5 | Среднее время удержания | `{holdAvg·0.001:.3} U` |
| 6 | Скорость spm | `{spm:.2} ({spm0:.2})` |
| 7 | Скорость wpm | `{0.2·net:.2} ({0.2·net0:.2})` |
| 8 | Скорость нетто | `{net:.2} ({net0:.2})` |
| 9 | Скорость брутто | `{gro:.2} ({gro0:.2})` |
| 10 | Скорость брутто+ | `{groP:.2} ({groP0:.2})` |
| 11 | Скорость брутто* | `{groS:.2} ({groS0:.2})` |
| 12 | Потери от исправлений | `{loss:.2}%` |
| 13 | Аритмия | `{arrAll:.2}% ({arrClean:.2})%` |
| 14 | Исправлений | `{erasedN} ({corrPct:.2}%)` |
| 15 | Серий исправлений | `{erasedSeries} ({seriesPct:.2}%)` |
| 16 | max без исправлений | `{maxRun} ({maxRunPct:.2}%)` |

- wpm считается от **нетто** (слово = 5 знаков).
- `trunc` — это `__ftol` (0x55c41c), режим округления «к нулю».
- В строке 13 закрывающая скобка стоит перед `%`: `12,34% (5,67)%`. Литерал `")%"` — так в оригинале.

### FormatTime(ms, d) (0x40332c)
```
m = ms / 60000 (int)
s = FloatToStrF((ms % 60000)·0.001, ffFixed, 15, d) + S
if m: s = IntToStr(m % 60) + M + " " + s
      if m/60: s = IntToStr(m/60) + H + " " + s
```
`H`/`M`/`S` = `DAT_0058e208/20c/210`. Умолчания: «ч», «м», «с»; в LoadLanguage их переопределяет .lng.
Пример: `1ч 5м 3,250с`.

## Разметка стёртых символов (Recalculate, 0x40d6xx)
Сначала у всех записей снимаются `0x100` и `0x40000000`. Затем проход **с конца** по нажатиям:
- BackSpace без Ctrl → `bs++`.
- BackSpace с Ctrl (`flags & 0x800`) → `cbs++`, `mode = 0`.
- Нажатие, у которого `KeyDisplayName` длиной 1 (символ):
  - `cbs == 0`: если `bs > 0` → пометить `0x100`, `bs--`;
  - `cbs > 0` (Ctrl+BackSpace стирает слово, но не пробел перед ним):
    повторять, пока `cbs > 0` и символ «не подошёл»:
    - `c` — пунктуация из ``!";%:?*(-=+\/#@`~[]{}'<>,.``: если `mode == 0`, то `mode = 1`;
      при `mode == 1` пометить, иначе стоп;
    - `c == ' '`: при `mode == 0` пометить (пробелы сразу перед курсором); иначе стоп;
    - иначе (буква, цифра, `\r`…): если `mode == 0`, то `mode = 2`; при `mode == 2` пометить, иначе стоп;
    - стоп → `cbs--`, `mode = 0`, `bs = 0`, и тот же символ проверяется для следующего Ctrl+BS.

  Итог: Ctrl+BS съедает пробелы непосредственно перед курсором, затем один прогон букв **или**
  пунктуации. Пробел перед словом остаётся. Это совпадает с описанием пользователя.
- Не-символьные нажатия (стрелки, модификаторы) счётчики не сбрасывают.

## Особенности, которые надо воспроизвести
- `avgClean` по умолчанию `1.0`, `avgAll` — `0`.
- В `min/max/средней паузе` учитываются паузы всех элементов, включая BackSpace и модификаторы.
  Делится же средняя пауза только на число символов (`nAll`).
- `local_4cc = (элементов с флагом 0x1000) / (серий таких элементов)` вычисляется, но не выводится.
  Мёртвый код, в порт не нужен.
- `pressT[vk]` после отпускания не сбрасывается: повторное отпускание той же клавиши даст
  лишнее удержание. В реальных данных это невозможно, потому что Recalculate выкидывает
  отпускания ненажатых клавиш.
- Счётчик dt в Recalculate (`local_24c`) — uint32 мкс: переполнится на паузе больше ~71 мин.
  Реальные паузы так далеко не заходят; такие данные в любом случае помечаются как начало фрагмента.

## Локализация (0x41c794, для этапа i18n)
Файл `<exe dir>\<Language>.lng` (INI):
- секция `Main`;
- ключи — строки-номера;
- для каждого контрола Form1 читается `ReadString("Main", "<N>", <текущая подпись>)`.

Три цикла по номерам: `IntToStr(i + 0x12f)` для i < 7, `i + 0x352` для i < 17
(по количеству — вероятно, пункты CheckListBox1) и `i + 0x456` для i < 9.
Там же задаются `DAT_005b1470` (единица «мс» = подпись Label2) и суффиксы времени
`DAT_0058e208/20c/210`. Точные номера ключей — при реализации i18n,
читать `re/decomp_clean/one_0x41c794.c` вместе с `disasm.py` (литералы ключей потеряны в декомпиляции).
