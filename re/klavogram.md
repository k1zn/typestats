# Клавограмма (PaintBox3)

Порт — `src/ui/KlavogramWidget`. Объект клавограммы — `DAT_005b1348` (юнит «Midiedit»): записи 40 Б в векторе
`+0x30..+0x34` (`{t, tSeg, tDraw: int64 мкс; flags; ch; down}`, см. `text_reconstruction.md`), рисует в TBitmap `+0x28`,
который `FUN_00437134` копирует на PaintBox3. Эталон вида — `re/ui_reference/main_legend.png`.

## Состояние объекта

| поле | смысл | начальное |
|---|---|---|
| `+0x00` top | верх первой дорожки, px | 30 |
| `+0x04` rowH | высота дорожки, px | 28 |
| `+0x08` cursorX | x мыши (обновляется, только если x > 0) | −1000 |
| `+0x0c` selX | x начала измерения | |
| `+0x10` curT / `+0x18` selT | абсолютное время курсора / начала измерения, мкс (int64) | |
| `+0x20` cursorMode | режим курсора (двойной клик переключает) | 0 |
| `+0x21` selecting, `+0x22` selPending | идёт измерение / его начало ещё не зафиксировано | 0 |
| `+0x68` scroll | время левого края, мс (float) | 0 |
| `+0x6c` zoom | px на мс (float), 0.04..300 | 0.25 |

Шрифт — Arial 9 pt. `FUN_00437a3c(h)` (из `Panel8Resize`): `rowH = (h − textHeight("1")) / 9`, `top = h − 9·rowH`.
Дорожек 9 — **по пальцам** текущей расстановки (`DAT_005b1278[scan & 0x7f]` → 0..8: ЛМ, ЛБ, ЛС, ЛУ, ПУ, ПС, ПБ, ПМ,
остальные клавиши), а не по рядам клавиатуры.

## Отрисовка (`FUN_00435650`)

`x(rec) = trunc((0.001·tDraw − scroll) · zoom)` (extended, усечение), `W` — ширина.

1. Фон `RGB(255,255,220)` (0xdcffff).
2. Первая видимая запись: `first = lower_bound(tDraw ≥ trunc(scroll·1000))`. Старт обхода — назад от `first`, пока не
   встретятся записи всех 9 пальцев (или начало): так восстанавливаются клавиши, зажатые до левого края.
3. Режим курсора: ищется запись, ближайшая к `cursorX` (обход с начала, стоп когда расстояние начало расти или
   `px > W`). Если до неё ≤ 8 px — курсор прилипает (`curX = trunc(px)`, время = её `tDraw`), иначе `curX = cursorX`,
   время = `trunc((cursorX / zoom + scroll) · 1000)`. Время переводится в абсолютное (`FUN_00435578`:
   `lower_bound(tDraw ≥ v)`, за концом — последняя; `v − rec.tDraw + rec.t`). При `selPending` запоминаются `selT`, `selX`.
   При `selecting` — заливка `RGB(255,255,180)` от `selX` до `curX` на всю высоту ниже `top`.
4. Шкала времени. Шаги `{1,2,5,10,20,50,100,200,500,1000,2000,5000,10000,60000}` мс, знаков после запятой
   `{3,3,3,2,2,2,1,1,1,0,0,0,0,0}`. Берётся первый шаг, для которого
   `step > trunc(textWidth(FormatTime(trunc(W/zoom + scroll), digits) + "W") / zoom)` (`w` — эта ширина текста).
   Первая метка: `t0 = trunc((scroll − w/2) / step − 1) · step + step − scroll` (мс от левого края), дальше `+ step`,
   пока `trunc(t·zoom) < W + w/2`. Для метки `v = round(t + scroll) ≥ 0`: текст `FormatTime(v, digits)` по центру над
   дорожками (`y = top − textHeight − 1`) и вертикальная пунктирная (psDot) линия `RGB(175,175,175)` от `top` до
   `top + 9·rowH`.
5. Записи по порядку от старта. Состояние: списки зажатых клавиш по пальцам (новая — в начало; узел
   `{flags, ch, level}`), `segX[9]` — начало незакрашенного участка, `lastX[9]`, `held` — сколько клавиш зажато.
   Для каждой записи (`x` — её координата, `f` — палец):
   - для каждого пальца с непустым списком: если `x ≥ 0` — прямоугольник `[segX, x) × дорожка` цветом
     `color[level первой в списке][held > 1]`; затем `segX = x`;
   - если `x ≥ 0` и у пальца `f` есть зажатые: подпись первой в списке — `KeyDisplayName`; `[LShift]`/`[RShift]` → ⇑,
     `[BackSpace]` → ←, `[Ctrl+BackSpace]` → ⇐, Enter → ↵ (в оригинале — символы 0xDD, 0xAC, 0xDC, 0xBF шрифта
     Symbol). Рисуется по центру отрезка `[lastX[f], x]` и дорожки, если `textWidth < x − lastX[f] − 1` и
     `textHeight < rowH`. Рамка: обычная клавиша — чёрные вертикали на `lastX[f]` и `x − 1`; стёртая (0x100) —
     красный, а injected (0x1000) — синий прямоугольник пером 3 px: `(lastX+1, y) … (x−2, y+rowH−2)`;
   - отпускание: из списка пальца убираются узлы с тем же VK;
   - нажатие с `x ≤ W`: `segX[f] = x`; пробел (VK 0x20) — чёрная штриховая (psDash) вертикаль на всю высоту
     дорожек; если клавиши с таким VK в списке нет — добавить в начало с `level = min(held, 4)`;
   - начало фрагмента (0x40000000) — чёрная вертикаль 2 px;
   - `held` = сумма длин списков; если у пальца до этой записи были зажатые, `x −= 1`; `lastX[f] = x`;
   - стоп, когда `x > W` и `held == 0`.
6. Горизонтали `y = top + i·rowH − 1`, `i = 0..9`, чёрные; толщина 2 при `i = 0, 4, 8` (верх, граница рук, граница
   «остальных»), иначе 1.
7. Режим курсора: вертикаль на `curX`; при измерении — вторая на `selX` и плашка `RGB(255,230,230)` с рамкой
   у курсора (`left = curX`, `top + 2`, ширина `max(w1, w2) + 6`, высота `2·th + 4`) с двумя строками:
   `|curT − selT| · 0.001` мс с 3 знаками + « мс» и скорость с 2 знаками + « зн/мин». Скорость (`FUN_00437ac8`):
   среди записей между курсорами — нажатия нестёртых односимвольных клавиш, `n` штук, время первой и последней;
   `(n − 1) · 6e7 / (tLast − tFirst)`, 0 если разница < 10 мкс.

Цвета участков `DAT_0059a0c4` (BGR → RGB), по уровню — сколько клавиш уже было зажато в момент нажатия:

| level | одна зажата | зажато несколько |
|---|---|---|
| 0 | (180,240,180) | (34,172,34) |
| 1 | (32,209,247) | (6,149,179) |
| 2 | (233,154,252) | (202,18,248) |

## Мышь (PaintBox3MouseDown/Move/Up, FormMouseWheel)

- левая кнопка + движение: `scroll += (xPrev − x) / zoom`;
- правая + движение: `zoom −= 0.01 · (xPrev − x) · zoom`, в пределах 0.04..300;
- средняя + движение: `scroll += (xPrev − x) · 50 / zoom`;
- левая и правая вместе: измерение (`selecting`), в режиме курсора показывается плашка;
- двойной клик: переключить режим курсора;
- колесо над клавограммой: `scroll −= delta / (2 · zoom)`;
- после любого изменения: `scroll ≥ −0.75 · W / zoom`, `scroll ≤ max(0, 0.001 · tDraw последней записи)`; затем
  `FUN_00424e64` (диапазон элементов, видимых на клавограмме → жёлтая подсветка в тексте и положение графика),
  ListView1 (`FUN_00404c44`), перерисовка графика.

`FUN_00424e64`: записи клавограммы `[lower_bound(tDraw ≥ scroll·1000), lower_bound(tDraw ≥ (scroll + W/zoom)·1000))`
→ элементы через якоря (klav → elem) → `FUN_0043a8fc(модель, e1, e2)`.
