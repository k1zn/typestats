# Графики главного окна (PaintBox1): серии

Порт — `src/core/Graphs`. Серии — объекты с `vector<float>` по `+0x24/+0x28`; создаются в
`TForm1::FormCreate` (0x408456…0x409775) вместе с подписями легенды:

| Глобал | Подпись (0x58f778…) | Ключ видимости в реестре | Порт |
|---|---|---|---|
| `DAT_005b13ec` | Мгновенная скорость | `VgrCurSpeed` | `curSpeed` |
| `DAT_005b13f0` | Средняя скорость | `VgrMedSpeed` | `medSpeed` |
| `DAT_005b13fc` | Классическая скорость | `VgrClassicSpeed` | `classicSpeed` |
| `DAT_005b1400` | Приведённая скорость | `VgrPrivSpeed` | `privSpeed` |
| `DAT_005b13f4` | Мгновенная ритмичность | `VgrCurRythm` | `curRhythm` |
| `DAT_005b13f8` | Средняя ритмичность | `VgrMedRythm` | `medRhythm` |
| `DAT_005b140c` | Гистограмма аритмии | `VhsPeriodMed`? | `arrhythmia` |
| `DAT_005b1408` | Гистограмма длительностей (= паузы элементов) | `VhsPeriod`? | `pause` |
| `DAT_005b1404` | зона пальца элемента (`DAT_005b1278[scan & 0x7f]`), не график | — | ещё нет |

Соответствие `Vhs*` и гистограмм уточнить при портировании отрисовки (PaintBox1Paint → 0x43c6bc).

## Когда считаются
Recalculate на каждом элементе пушит паузу в `DAT_005b1408`. На первом элементе фрагмента
(флаг `0x40000000`) сначала вызывает `FUN_00403868(segStart)` для прошлого фрагмента, затем пушит
`−2147483648.0` (`0xCF000000`) во все серии, кроме пальцев, и `segStart = size`. В конце прохода —
ещё один вызов `FUN_00403868(segStart)`. То есть серии выровнены по элементам, а у маркера во всех
сериях стоит маркер. Порт считает то же по готовому вектору пауз: фрагменты — непрерывные участки
между маркерами.

## FUN_00403868(from), элементы [from, n)
Все значения — float; промежуточные вычисления в x87 extended, округление до float на каждой
записи (порт использует `long double` MinGW, тоже 80 бит). p = pause[i], k = i − from.

```
cur[i]  = p > 10 ? 60000 / p : 0                   // порог 10.0f @0x404554, иначе 0.0 (double @0x40455c)
sum    += p
med     = smooth(pause, from, n)                   // FUN_0043d4cc, см. ниже
avg     = sum / (n − from)
cum = 0
для каждого i:
    cum += p
    r = avg > 0.01 ? |p − avg| / avg : 0;  r = min(r, 1)       // fabs = 0x55c3d8, аргумент — double
    curRhythm[i] = (1 − r) · 100
    med[i]       = med[i] > 10 ? 60000 / med[i] : 0             // скорость из сглаженной паузы
    arrhythmia[i]= avg > 0.01 ? 100 · p / avg − 100 : 0
    classic[i]   = cum > 10 ? (k·60000 + 120000) / cum : 0      // (k+2) знаков
    priv[i]      = cum > 10 ? (k·60000 + 60000) / cum : 0       // (k+1) знаков
medRhythm = smooth(curRhythm, from, n)
```
Декомпиляция Ghidra тут ошибается: показывает порог `10.0` вместо ветки `0.0` и теряет аргумент fabs.
Проверено по `disasm.py`. Там же накапливается `local_7c += 2·r` — не используется.

## FUN_0043d4cc(src, dst): сглаживание
Работает с `from = dst.size()` до `src.size()`:
```
a = 0.03f
prev = среднее src[from .. from + min(n, 15))
для i: prev = (1 − a)·prev + a·src[i]; dst.push(prev)
```

## Сверка
`diffstand.py` читает серии из памяти оригинала (указатели на объекты по адресам выше) и пишет
биты float в `tests/golden/orig/*.json` (`series`); `tst_orig` сравнивает побитно.
