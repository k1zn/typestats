# Зоны пальцев (расстановка пальцев по клавишам)

Порт — `src/core/FingerZones`. Объект расстановки в оригинале — глобал `0x5b1078`:

| смещение | поле |
|---|---|
| +0x000 … +0x1ff | 8 × `std::deque<int>` (по 0x40 Б) — скан-коды клавиш пальца, **первый — клавиша начальной позиции** |
| +0x200 (`DAT_005b1278`) | `byte[128]`: палец по `scan & 0x7f`, 0..7, **8 = «Остальные клавиши»** (не распределена) |
| +0x280 (`DAT_005b12f8`) | флаг «только чтение»: 1 у встроенной схемы, редактор Tkbd её не меняет |

Пальцы: 0 — левый мизинец, 1 — левый безымянный, 2 — левый средний, 3 — левый указательный,
4 — правый указательный, 5 — правый средний, 6 — правый безымянный, 7 — правый мизинец,
8 — «Остальные клавиши» (строки `0x59dcb0…`, таблица указателей `0x59dbdc`). Рука: палец < 4 — левая.

## Функции
| адрес | что |
|---|---|
| `0x449f74` | очистить: таблица ← 8, деки пусты, флаг ← 0 |
| `0x44a1fc` | встроенная схема (таблица `0x59e204`, 8 × 16 int, 0 — конец списка), флаг ← 1 |
| `0x449fb4(obj, str, finger)` | разбор строки пальца: пары hex-цифр, `StrToIntDef("0x"+пара, 0)`; значение < 0x80 → `push_back` в дек пальца и `table[scan] = finger`. Непарный последний символ отбрасывается, мусор даёт скан 0 |
| `0x44b028(obj, finger)` | строка пальца: `IntToHex(scan, 2)` всех элементов дека подряд (заглавные) |
| `0x44b1bc(obj, scan)` | клавиша начальной позиции: `table[scan&0x7f] < 8` и первый элемент дека пальца == scan |
| `0x44b2b0(a, b)` | равенство схем: таблицы совпадают (128 Б) и у каждого непустого пальца совпадает первый элемент |
| `0x44a298(obj, scan, finger, home)` | редактор: убрать скан из дека прежнего пальца (если он < 8); если прежний палец == finger и не home — ничего. Затем finger < 8: `home ? push_front : push_back`, `table[scan] = finger`; finger == 8 → `table[scan] = 8` |

Встроенная схема «Стандарт» (`0x59e204`; имя — строка `0x58eb35`, переводится через .lng):
```
0 левый мизинец      1E 2C 10 29 02 2A        A Z Q ` 1 LShift
1 левый безымянный   1F 2D 11 03              S X W 2
2 левый средний      20 2E 12 04              D C E 3
3 левый указательный 21 2F 30 22 13 14 05 06 07   F V B G R T 4 5 6
4 правый указат.     24 31 32 23 15 16 08     J N M H Y U 7
5 правый средний     25 33 17 09              K , I 8
6 правый безымянный  26 34 18 0A              L . O 9
7 правый мизинец     27 35 28 19 1A 1B 0B 0C 0D 2B 36   ; / ' P [ ] 0 - = \ RShift
```
Пробел, Enter, BackSpace, Tab, CapsLock, Ctrl, Alt, Win — 8.

## Хранилище схем: `FingerZones.ini` рядом с exe
`TIniFile` (`0x402e74`), ANSI (cp1251). Секция — имя схемы, ключи `Finger0`…`Finger7` — строки пальцев:
```ini
[Моя]
Finger0=1E2C10292A
...
```
- Список схем (ComboBox4 главного окна): `ReadSections`, затем в позицию 0 вставляется «Стандарт».
- Выбор (`0x403160(name)`): имя ≠ пункт 0 → очистить и прочитать `Finger0..7` секции (по умолчанию ""),
  иначе встроенная схема.
- Запись (`0x402ff0`): текущая схема пишется в секцию своего имени, кроме встроенной.
- «Новая» (SpeedButton9Click `0x428aec`): запрос имени (InputQuery «Создание расстановки пальцев» /
  «Название расстановки»); если имени нет в списке — текущая схема под новым именем, флаг ← 0, запись.
- «Удалить» (правая кнопка SpeedButton9, `0x428c34`): встроенную нельзя (сообщение); иначе подтверждение,
  `EraseSection`, выбор пункта 0.
- Имя текущей схемы хранится в реестре: `FingerZonesName` (по умолчанию пункт 0).

## В .tsf
`SaveTsf` пишет `FingerZonesName` и `Finger0..7` **только если выбрана не встроенная схема**
(ItemIndex ComboBox4 ≠ 0). `LoadTsf`: если есть `FingerZonesName` — строки `Finger0..7` разбираются во
временную схему, затем (`0x415f70`) ищется равная ей (`0x44b2b0`) среди всех схем списка по порядку.
Нашлась — выбирается она. Нет — имя из файла, пока оно занято, дописывается `_` (`0x5902aa`); схема
становится текущей под этим именем, добавляется в список и пишется в INI.

## Серия пальцев `DAT_005b1404`
Recalculate на каждом элементе текста (включая первый элемент фрагмента, маркера здесь нет) пушит
`(float) table[flags & 0x7f]` исходной записи. Это не график: серию читают доп. статистика (Form3,
0x43ff3c: `≤ 7` — палец, `< 4` — левая рука) и гистограммы Form4. Стенд читает её как `series.finger`.

## Tkbd «Клавиатура» — редактор зон
Форма 802×181, PaintBox1 — клавиатура, PaintBox2 справа — палитра из 9 пальцев (текущий — жирным,
`DAT_0059dc10`, выбор кликом: `index = y·9 / высота`).
- Клавиши (`0x59d878`, 52 записи по 16 Б: `float x, y, w` в единицах клавиши, затем `byte scan`):
  ряд 0 `29 02…0D 2B 0E` (x = 0…14, w = 1); ряд 1 `0F`(w 1.5) `10…1B` с x = 1.5…12.5;
  ряд 2 `3A`(w 1.75) `1E…28`; ряд 3 `2A`(w 2.25) `2C…35`, `36`(w 2.75). Enter (0x1C) рисуется отдельно
  двумя прямоугольниками цвета своего пальца (код 200 в хит-тесте `0x448e10`). Пробел не рисуется.
- Подпись клавиши: `KeyDisplayName` от `MapVirtualKeyEx(scan, MAPVK_VSC_TO_VK_EX)` + `ToUnicodeEx` по
  раскладке окна (`0x448fe8`); длина 1 — шрифт 16, иначе 10; мёртвая клавиша — с белой вставкой.
- Заливка — цвет пальца (`0x59dbb8`, COLORREF): `B4F0B4 F7D120 FFA5F0 C8C8FF 6028E6 F812CA FF9506 22AC22`,
  8 — `FFFFFF`. Клавиша начальной позиции обведена пером толщиной 4.
- Левый клик — клавишу текущему пальцу (`0x44a298(home=0)`), правый — сделать её начальной
  позицией пальца (`home=1`). Для схемы «только чтение» клики игнорируются.
