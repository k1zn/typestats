# Журнал `.tsj`

Порт — `src/core/Journal`. Журнал — непрерывная запись всех перехваченных событий в файл рядом с программой:
по файлу на месяц. Включается настройкой «Вести журнал» (`Form8` +0x364, ключ реестра `JournalOn`).

## Где живёт

- Поток — `std::ofstream*` в `DAT_005b0fe0` (STLport: режим `0x17` = `out | binary | ate | app`, т.е. дозапись).
- Имя (`FUN_00402a80`): `ExtractFilePath(exe) + IntToStr(год) + "_" + IntToStr(месяц) + ".tsj"` по `Now()`
  (`DecodeDate`). Месяц без ведущего нуля: `2026_9.tsj`. Литералы `"_"` = 0x58eeb7, `".tsj"` = 0x58eeb9.
- Открывается в `FormCreate` (0x40739c…, присваивание `DAT_005b0fe0` на 0x…3165 декомпиляции) **всегда**, даже если
  журнал выключен — поэтому оригинал при каждом запуске оставляет пустой `<год>_<месяц>.tsj`.
  Закрывается в `FormDestroy` (0x429734).
- Имя вычисляется один раз при открытии потока: сеанс, переживший смену месяца, пишет в старый файл.

## Запись (OnKeyEvent 0x40a7a4, перед добавлением записи в вектор)

Пишется то же событие, что попадает в вектор записей (т.е. после хоткеев, при включённом перехвате, не в своём
окне, после фильтра «отпускание ненажатой клавиши»), если отмечено «Вести журнал»:

| байты | поле |
|---|---|
| 4 | `dt ^ 0x554973` (uint32 LE; dt — мкс от предыдущего события, как в `.tsf`) |
| 4 | `flags` (uint32 LE, как в памяти; бит 0x100 в этот момент не стоит) |
| 4 | `ch` (uint32 LE, символ в младших 16 битах) |
| 1 | `n` — длина комментария в байтах: **младший байт** длины AnsiString |
| n | комментарий, cp1251, без завершающего нуля |

После каждой записи — `flush` (`FUN_0040afbc`). Заголовка и подписи нет; записи идут подряд.

Комментарий здесь — только автокомментарий (`DateTimeToStr(Now) + " " + заголовок окна ≤ 80 символов`), так что
длиннее 255 он не бывает. Формально при длине ≥ 256 оригинал записал бы `len mod 256` байт; порт обрезает до 255.

## Чтение (`FUN_0042abcc(Form1, path)`)

1. Закрыть текущий поток журнала (файл может быть тем же).
2. `std::ifstream(path, in | binary)` (режим `0xc`).
3. `Button2Click` — очистить текущую запись.
4. Цикл: прочитать 4 байта → `dt ^= 0x554973`; 8 байт → `flags`, `ch`; 1 байт → `n`; если `n ≠ 0` — `n` байт
   комментария. Любое неудавшееся чтение (`badbit | failbit`) завершает цикл: неполная запись в хвосте
   отбрасывается. Каждая полная запись добавляется в вектор `{dt, flags, ch, comment}`.
5. `Recalculate`; имя файла документа = `""` (сохранение спросит имя `.tsf`); заголовок окна —
   `<название программы> - Журнал <имя файла>` (на стенде: `Typing statistics v1.43c - Журнал 2026_9.tsj`);
   `g_fileClean = true`, панель «Файл повреждён» скрыта.
6. Снова открыть на дозапись журнал **текущего месяца** (`FUN_00402a80`).

Зон пальцев, автора и пр. в журнале нет — остаются текущие.

## Откуда вызывается

- `SpeedButton26Click` (0x42b934, «Открыть журнал»): `FUN_0042abcc(текущий журнал)`; хук на время снимается.
- `SpeedButton6Click` (0x418ce8, «Открыть»): фильтр диалога `Typing statistics files|*.tsf|Typing statistics
  journals|*.tsj`; если `ExtractFileExt(имя) == ".tsj"` (0x5902dd, сравнение с учётом регистра) — журнал,
  иначе `LoadTsf`.

## Порт

- `Journal::fileName(date)`, `encode(record)`, `decode(bytes)`, `read(path, records)`, `JournalWriter` (дозапись
  с `flush` после каждого события).
- Сознательные отличия: каталог журнала задаёт вызывающий (рядом с exe писать можно не везде); файл создаётся при
  первой записи, а не при запуске; имя файла берётся по дате события, так что новый месяц — новый файл;
  расширение сравнивается без учёта регистра.

## Стенд

`python re/scripts/diffstand.py <файл.tsf> --journal` (~10 с): `tsstat --to-journal` пишет записи `.tsf` журналом
порта в `<каталог exe>/<год>_<месяц>.tsj`; оригинал открывает сам `.tsf` (запоминаются текст, стили, ListView2), затем
журнал кнопкой SpeedButton26 (Form1 +1144) — должно получиться то же самое. Существующий непустой журнал этого месяца
стенд не трогает (отказывается работать), свой файл после прогона удаляет.

Проверено: `обыка.tsf` и его копия с комментариями у трёх записей («(…)» в строке, отдельным абзацем, с `;` внутри) —
текст, стили (зелёные комментарии) и статистика совпали. Запись журнала самим оригиналом не проверялась (нужно
включать «Вести журнал» и печатать в живую систему); формат записи взят из дизассемблера и симметричен чтению.
