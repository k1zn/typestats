## SpeedButton22Click (0x429a30)

1. `RemoveHook()` — пока форма открыта, запись не ведётся.
2. Запоминает индекс языка, `ShowModal`.
3. **Ok:**
   - если индекс языка изменился: имя пункта → `DAT_005b1464`; индекс 0 (встроенный язык) — сообщение
     «Для смены языка перезапустите Ts» (заголовок «Предупреждение»); иначе `LoadLanguage` сразу
     (и перезаполнение ComboBox4 главного окна); затем `FUN_00407140` — запись общих ключей реестра
     (автор, имя пресета, язык…);
   - `FUN_00429bbc` — применение;
   - `FUN_00406a90` — сохранение пресета.
4. **Отмена:** `FUN_0041ab08` — пресет перечитывается, контролы формы возвращаются к сохранённым значениям.
5. `InstallHook()`.

## Применение (FUN_00429bbc)

Вызывается и после загрузки пресета (`FUN_0041ab08`).

1. `Memo4.Font.Size = UpDown1` — размер в пунктах (12 pt = 16 px при 96 dpi); то же для RichEdit формы
   «Ввод текста» (Form9).
2. Шрифт канвы клавограммы (`DAT_005b1348[10]`) — `UpDown2` пунктов.
3. CheckBox9 ≠ `TrayIcon.Visible` → значок в трее показывается/прячется, кнопка приложения на панели задач
   прячется (`ShowWindow(Application.Handle, SW_HIDE)`) или возвращается (`SW_SHOW`).
4. `FUN_00404a78` — строки ListView2 по галочкам CheckListBox1; высота ListView2 = (число отмеченных + 1) строк
   (`LVM_APPROXIMATEVIEWRECT` от `count − 1`).
5. `Recalculate`, затем пересчёт геометрии клавограммы (`FUN_00437a3c` с высотой PaintBox3, `FUN_00435650`,
   `FUN_00437134`) — высота дорожек зависит от шрифта.
6. `DAT_0058e1d0 = UpDown3` — число знаков после запятой в ListView1 (пауза и длительность), `FUN_00404c44`.
7. `opLoSpeed = StrToIntDef(Edit1, 200)`, `opHiSpeed = StrToIntDef(Edit2, 600)`.
8. CheckBox6: маска процессоров 1 либо все.

## Порт

- `src/ui/SettingsDialog`: та же геометрия; CheckBox6 нет (выкинут сознательно); числа — QSpinBox.
- Язык: список Russian / English (ключ `Language`). Смена языка — после перезапуска, с тем же сообщением
  (оригинал так ведёт себя при возврате к встроенному языку).
- Хук на время формы не снимается: клавиши в собственных окнах Recorder и так не записывает.
- `MainWindow::applySettings()` — пункты 1, 2, 4–7. Трей — отдельным этапом.
- **Тёмная тема** (своя, у оригинала её нет): кнопка в правом углу тулбара (месяц / солнце), ключ `DarkTheme` в корне
  настроек (не в пресете), сразу, без перезапуска. Первый запуск (ключа ещё нет) берёт тему системы и сохраняет её —
  дальше системная не учитывается (`Look::applySavedTheme`). `Look::setDark` — Fusion с тёмной палитрой на всех ОС (родной стиль
  Windows тёмным не бывает) и тёмная схема Qt (тёмный заголовок окна на Windows); самописные панели берут цвета из
  `Look::colors()` при отрисовке (светлый набор — цвета оригинала, снимки светлой темы побайтно прежние). Что держит
  цвета у себя, обновляет `MainWindow::updateThemeColors()`: плашка «Файл повреждён», легенда, Form10, документ текста
  (перестраивается, выделение и прокрутка сохраняются). Tkbd и баннер Form7 — рисунки, не перекрашиваются.
  `--theme dark|light` — тема на один запуск без сохранения (снимки).

# Пресеты, реестр, трей, «Ввод текста», «О программе»

## Реестр оригинала и пресеты

`TRegIniFile("Software")`, секция `TypingStatistics` либо `TypingStatistics\<имя пресета>` (`FUN_004035cc`):
- значения безымянного пресета лежат прямо в `HKCU\Software\TypingStatistics`, именованного — в подключе с его именем;
- там же, в корне, общие значения (`FUN_00407140`): `UserName` (автор для новых файлов), `Profile` (имя текущего
  пресета), `MainWinLeft`, `MainWinTop`, `Language`;
- список ComboBox1 — подключи; при `Profile = ""` комбобокс пуст.

Обработчики:
- `ComboBox1Select` (0x4283fc): сохранить текущие настройки в прежний пресет (`FUN_0040b514`), имя ← выбранное,
  загрузка (`FUN_0041ab08`), запись общих ключей, Recalculate;
- `SpeedButton8Click` (0x4282f4): InputQuery «Создание нового пресета настроек» / «Название пресета»; текущие
  настройки пишутся под этим именем, имя добавляется в список и выбирается;
- `SpeedButton8MouseDown`, правая кнопка (0x428488): при непустом имени — подтверждение «Вы действительно хотите
  удалить пресет?» / «Удаление пресета», `EraseSection`, пункт убирается; список пуст → имя ← "", иначе выбирается
  и загружается пункт 0.

Порт (`src/ui/Presets`): рабочие настройки — в корне QSettings под теми же ключами, пресет — их копия в группе
`Presets/<имя>` (без общих ключей и `WindowGeometry`). Первый запуск на Windows (`Presets::importFromOriginal`, флаг
`RegistryImported`) переносит значения и пресеты оригинала из его ключа реестра; размер и положение окна берутся из
`MainWinWidth/Height/Left/Top`, пока нет своего `WindowGeometry`.

## Трей и выключение перехвата

- `TrayIcon1` (иконки из ImageList1, меню PopupMenu4: «Вкл» с галочкой, «Оперативная статистика», «Выход»; левый клик —
  восстановить окно). Виден при «Сворачивать в трей» (`MinimizeToTray`); при этом кнопки приложения на панели задач нет.
  «Сворачивать при старте» (`AutoMinimize`) — окно сворачивается сразу после запуска.
- `CheckBox1Click` (0x40c2a8, галочка «Вкл» и хоткей F8+F9): заголовок приложения и подсказка значка — `Ts: ON` /
  `Ts: OFF`, значок меняется. При выключении для каждой клавиши, которая по записям осталась нажатой (по VK),
  дописывается отпускание: `dt = 50000`, `flags = vk << 16 | 0x2000`, `ch = 0` — иначе клавограмма держала бы её
  до конца. Затем фокус уходит в текст.

Порт: `Recorder::appendReleases`, `MainWindow::captureToggled`; значок — `QSystemTrayIcon` (иконка приложения, при
выключенном перехвате — её серый вариант). Кнопка на панели задач прячется только у свёрнутого окна.
Заголовок приложения (`Application->Title`: «Ts: ON» при старте — FormCreate 0x407c34, «Ts: ON»/«Ts: OFF» —
CheckBox1Click) у VCL принадлежит скрытому окну приложения, которое и держит кнопку на панели задач. В Qt кнопку держит
главное окно, поэтому состояние стоит в начале его заголовка: «Ts: ON - Typing statistics v… - файл»
(`MainWindow::updateTitle`).

## Form9 «Ввод текста»

Окно-инструмент поверх всех окон с RichEdit (Arial, размер — «Размер шрифта: Текст»). Открывается кнопкой SpeedButton23
и F4 в главном окне. Esc — закрыть, F2 — очистить; «Очистить» главного окна очищает и его. Набор в этом окне
записывается (для хука оно «своё» только на Esc и F2), а текст главного окна пересчитывается, когда с последней клавиши
прошло больше 800 мс. Ключи: `TextWinLeft`, `TextWinTop`, `TextWinWidth`, `TextWHeight`.

# Экспорт в Excel

Оригинал передаёт таблицу Excel через OLE (`Dexcel::ExcelGraph` 0x439030, последний аргумент — строить ли диаграмму):
- главное окно, SpeedButton7Click (0x418ed0): все нажатия записи (`FUN_00437d98` без ограничения числа строк);
  столбцы «Клавиша», «Пауза, мс», «Длительность, мс» (подписи столбцов ListView1 + единица), с диаграммой;
  если нажатий нет — ничего;
- Form3, SpeedButton7Click (0x4457c4): «Текст», «Скорость»[, «Кол-во»] в порядке списка, без диаграммы.

Порт (`src/export/TableExport`): файл .xlsx (QXlsx; числа — числами, у списка клавиш — линейная диаграмма столбцов
пауз и длительностей) или .csv (UTF-8 с BOM; при десятичной запятой разделитель «;»), после записи файл открывается
программой по умолчанию.
