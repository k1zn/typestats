# Формат .tsf (Typing statistics file)

Восстановлено по `FUN_004160ac` (чтение, вызывается из `TForm1::SpeedButton6Click`),
`FUN_00415480` (запись, `TForm1::SpeedButton5Click`) и хуку `FUN_00404598` → `FUN_0040a7a4`.

## Общая структура

Текстовый файл, `TStringList::SaveToFile` / `LoadFromFile`: ANSI (cp1251), строки через CRLF.
Сначала идут строки данных (по одной на событие клавиатуры), затем строки заголовка
`имя=значение`. Их добавляет `TStrings::Values[]`, поэтому они оказываются в конце.

### Строка данных
```
TTTTTTTT KKKKKKKKKKKK[\t;комментарий]
```
- `TTTTTTTT` — `IntToHex(dt, 8)`: время **в микросекундах от предыдущего события**
  (QPC-разность × 1 000 000 / freq; поле `+0` записи).
- `KKKKKKKKKKKK` — `IntToHex(int64, 12)`: `(ch & 0xFFFF) << 32 | (flags & ~0x100)`.
- `\t;комментарий` — необязательно. Это текстовая метка («Пометить», «Автокомментарии»).

При чтении (tsfVersion ≥ 1):
1. `sscanf(line, "%x %s", &dt, buf) == 2`;
2. `TryStrToInt64("0x" + buf)` → flags (младшие 32 бита) и ch (старшие);
3. если в строке есть `;`, всё после первого `;` становится комментарием.

Строка, не прошедшая разбор, пропускается. Так пропускаются и строки заголовка.

tsfVersion = 0 (старые файлы): `sscanf("%d %d", &dt, &key)`. Младший байт `key` — ANSI-символ
(переводится в UTF-16). `vk = (key >> 16) & 0xFF`. Младший байт затем заменяется на
`MapVirtualKeyEx(vk, MAPVK_VK_TO_VSC, текущая раскладка)`.

### Заголовок (Values)
| ключ | значение |
|---|---|
| `tsfVersion` | `1` (если в файле > 1 — предупреждение «Этот файл создан в более поздней версии…») |
| `autor` | автор (Form2.Edit1) |
| `comment` | описание (Form2.Memo1), из текста удаляются `\r` и `\n` |
| `date` | дата (Form2.Edit3, `DateTimeToStr(Now)` при первом сохранении) |
| `signature` | подпись целостности, только если файл «чистый» (DAT_0058e1c5); см. ниже |
| `FingerZonesName` | имя расстановки пальцев |
| `Finger0`…`Finger7` | зоны пальцев (строка, формат — в finger_zones.md) |
| `AttachedVideo` | имя прикреплённого видео (относительно папки .tsf) |
| `VideoTimeShift` | сдвиг видео, мс (int) |

Если `signature` не совпадает, показывается Panel5 «Внимание! Файл повреждён!».

## Запись в памяти (24 байта, `std::vector` @ DAT_005b0fe8..fec)
| смещение | поле |
|---|---|
| +0x00 | `dt` — мкс от предыдущего события (uint32) |
| +0x04 | не используется / служебное |
| +0x08 | `flags` (см. ниже) |
| +0x0C | `ch` — UTF-16 символ (младшие 16 бит) |
| +0x10 | `AnsiString comment` |
| +0x14 | служебное |

## Биты flags (заполняются в хуке `FUN_00404598`)
| бит/маска | смысл |
|---|---|
| `0x000000FF` | scan code (`KBDLLHOOKSTRUCT.scanCode & 0xFF`) |
| `0x00000100` | служебный, при сохранении сбрасывается |
| `0x00000400` | Alt нажат |
| `0x00000800` | Ctrl нажат |
| `0x00001000` | LLKHF_INJECTED |
| `0x00002000` | отпускание клавиши (WM_KEYUP / WM_SYSKEYUP) |
| `0x00004000` | LLKHF_EXTENDED |
| `0x00008000` | ToUnicodeEx вернул 0 (нет символа); для отпусканий ставится всегда |
| `0x00FF0000` | VK code (`vkCode << 16`) |
| `0x01000000` | есть символ (ToUnicodeEx ≠ 0) |
| `0x04000000` | Shift нажат |
| `0x08000000` | ровно один символ (не комбинация с мёртвой клавишей) |
| `0x10000000` | VK_PACKET (0xE7): юникод-ввод, ch = scanCode |
| `0x20000000` | мёртвая клавиша (ToUnicodeEx < 0). Следующее нажатие с двумя символами переносит первый символ в эту запись и снимает бит |
| `0x80000000` | Win нажат |

## Обработка события (`FUN_0040a7a4`)
- **Хоткеи** (проверяются до записи; сами хоткеи не пишутся):
  - F8 (0x77) удерживается + F9 (0x78) → «Вкл»; F9 + F8 → «Выкл». Включается настройкой GlobalOnOff.
  - LCtrl (0xA2) + LWin (0x5B) → «Очистить» (Button2Click). Включается настройкой GlobalClear.
  - LCtrl + RShift (0xA1) → `FUN_00402c70(1)`: сброс оперативной статистики (событие записывается).
  - LCtrl + RCtrl (0xA3) → принудительный автокомментарий.
  - Ctrl+Alt+O (scan 0x18 при зажатых scan 0x38 и 0x1D) → показать/скрыть оперативную статистику.
- **Автокомментарий** (настройка AutoComments): если dt > 10 с или сменилось активное окно,
  комментарий = `DateTimeToStr(Now) + " " + заголовок верхнего окна`.
- **Фильтр автоповтора и отпусканий:** битовая карта нажатых scan-кодов (DAT_005b1300).
  Отпускание клавиши, которая не была нажата, игнорируется.
- **Перехват выключен** (CheckBox1) или фокус на окне самой программы (Form1, Form3, Form10;
  в Form9 только Esc/F2) → событие не пишется, круг таймера отменяется (время копится до следующей записи).
  Подробно и по порядку — `recording.md`.
- **Журнал** (JournalOn): событие дописывается в .tsj (`dt ^ 0x554973`, см. journal).
- **Оперативная статистика** (Form10), на нажатиях:
  - `speed = ((n − 1 − pauses) · 6e7) / Σdt_µs` [зн/мин], где n — символьные нажатия,
    а pauses — интервалы длиннее «Паузы разбиения» (UpDown1, мс);
  - `errors% = seriesBackspace · 100 / n`, где серия BackSpace считается один раз.
